# Collabject

> **Important:** Collabject is an external website and is not Object Collab or
> Object Workshop. Collabject is not made by, owned by, or affiliated with
> either project.

Here is the difference:

- **Object Workshop** is a mod for downloading *prefabs* made from vanilla
  Geometry Dash objects.
- **Object Collab** is an API mod that lets other mods add objects to the game.
- **Collabject** is this external website: a directory where you can find and
  download mods that rely on the Object Collab API (in other words, “modded
  objects”).

Collabject lists projects that build on Object Collab; it is not the API and it
does not provide Object Workshop prefabs.

## Got a project to add?

The quickest route is to [open a submission](../../issues/new?template=submit-project.yml).
Fill in what you know and include a public link that shows how the project uses
or supports Object Collab. A maintainer can take care of the registry entry.

If you'd rather add the entry yourself, copy [`registry/example.json`](registry/example.json)
and open a pull request. The full (still pretty short) walkthrough is in
[`CONTRIBUTING.md`](CONTRIBUTING.md).

Please get the developer's okay before submitting somebody else's project.

## What's in the registry?

Projects listed here can:

- add custom objects through Object Collab;
- use objects from other Object Collab mods;
- provide compatibility support;
- offer tools or resources for developers; or
- document something experimental or not yet released.

The registry is small on purpose: one JSON file per project, with useful links
and enough detail for somebody to understand the Object Collab connection.
