# Collabject

Collabject is a community hub and registry for Geometry Dash mods that use
or support Object Collab. Collabject is not to be confused with Object Collab itself.

## Submit a project

Use the repository's **Issues** tab and select **Submit an Object Collab project**.

Developers may also submit registry changes directly through a pull request.

## Registry categories

- Adds Object Collab objects
- Uses Object Collab objects
- Provides compatibility support
- Experimental or unreleased
