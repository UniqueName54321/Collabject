# Contributing to Collabject

## Submitting through an issue

The easiest submission method is the **Submit an Object Collab project**
form under the Issues tab.

## Submitting through a pull request

1. Fork this repository.
2. Copy `registry/example.json`.
3. Rename the copy using the project's Geode mod ID or project name.
4. Replace the example information with accurate project information.
5. Open a pull request.
6. Include evidence showing how the project uses or supports Object Collab.

## File names

Use lowercase letters and hyphens.

Examples:

- `lua-trigger.json`
- `developer-dialogue-objects.json`
- `object-groups.json`

## Relationship values

Use one of these values:

- `adds_objects`
- `uses_objects`
- `compatibility`
- `developer_tool`
- `experimental`

## Requirements

- Do not submit projects without the developer's permission.
- Do not claim support that cannot be publicly verified.
- Link to the Geode index, source repository, documentation, or another
  suitable source whenever possible.
- One project should generally use one registry file.
